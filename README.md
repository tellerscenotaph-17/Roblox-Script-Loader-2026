### What is XCutors?

XCutors is a Windows desktop application that bundles several popular Roblox script executors and a universal loader, allowing users to easily manage and switch between different tools for script execution and game customization.

XCutors itself is a management tool; however, the included executors are third-party software. Always download from the official GitHub repository and ensure your anticomponent is updated. Use at your own discretion.

### Which Roblox versions are supported?

The executors in XCutors are designed to work with current Roblox versions. Updates are released periodically to maintain compatibility after Roblox platform updates.

### How do I update the executors?

XCutors includes a built-in update checker. When a new version of an executor is available, you will be notified within the app and can update directly from the interface.

### Can I add my own scripts to the collection?

Yes, XCutors supports loading scripts from local files. You can organize your scripts in the designated folder and execute them through your chosen executor.

### Do I need administrator rights to run XCutors?

Administrator rights are recommended during installation and for initial setup, but you can run the application with standard user privileges afterward, depending on executor requirements.

### Is there a portable version available?

Yes, XCutors offers a portable installation option that does not require formal setup. Simply extract the ZIP file to a folder and run the executable directly.

### How do I switch between executors?

Use the main dashboard in XCutors to select your preferred executor from the list. The interface allows quick switching without needing to restart the application.
